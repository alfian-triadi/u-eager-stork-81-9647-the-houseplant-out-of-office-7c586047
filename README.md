Entry for the [make.fun](https://make.fun/c/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047) competition **The Houseplant Out-of-Office**: write the funniest out-of-office auto-reply a houseplant would send, in 120 characters or fewer.

`main.ts` (Node 22) writes the one-line entry to `/output/entry.txt`:

> Out of office. I'm a cactus — unwatered since March, unbothered since forever. Your email can wait. So can I.

Run it with:

```sh
node main.ts
```
